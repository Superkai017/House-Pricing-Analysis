# House Price Analysis

## Objective
The goal of this project is to analyze factors that influence house prices and build a predictive model to estimate property prices.

## Dataset
The dataset contains 4140 house records with features such as:
- number of bedrooms
- number of bathrooms
- living area
- year built
- location
- price

## Key Questions
1. What features most influence house prices?
2. Are bigger houses always more expensive?
3. Can we build a model to predict house prices?
